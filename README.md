# BeeReal

Studienprojekt an der DHBW Ravensburg zur Re-Identifikation einzelner Honigbienen am Flugloch, ohne Markierung.

Dieses Repo enthält zu jedem Paper das fertige PDF und die Belege dafür: den ausgeführten Code, die Ausgaben der Läufe auf Kaggle und die manuellen Auswertungen. Jedes Paper hat einen eigenen Ordner. Ein abgegebener Ordner wird danach nicht mehr geändert, spätere Papers kopieren, was sie brauchen.

| Ordner | Paper | Stand |
|---|---|---|
| [paper1](paper1/README.md) | Datenpartitionierung und Labeling per Tracking zur Re-Identifikation von Honigbienen | abgegeben am 24.11.2026 |

## Daten

Alle Versuche nutzen den Datensatz *thehiveisreal* von Mark Schutera (Hugging Face, `mrkschtr/thehiveisreal`, Lizenz CC BY-NC 4.0). Die Bienenbilder in diesem Repo sind Ausschnitte daraus und stehen unter derselben Lizenz. Die Videos selbst liegen nicht im Repo.
